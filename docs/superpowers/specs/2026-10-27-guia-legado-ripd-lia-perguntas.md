## RIPD (DPIA), quatro abas: Teste de Impacto, Conformidade, Armazenamento, Logs

### Teste de Impacto (duas seções: "Impacto da Atividade" e "Agentes de Tratamento")
1. Resultado Esperado
2. Benefícios
3. Existem terceiros responsáveis (Operadores) por parte das etapas de tratamento? **[final cortado: "...por parte das et"]**
4. Existem documentos que definam o escopo de atuação destes agentes? **[final cortado: "...escopo de atuação dest"]**

### Conformidade (29 perguntas, em 3 páginas no legado: 1 a 6, 7 a 16, 17 a 29)
1. Já foi identificado algum problema anterior com o cumprimento das normas de proteção de dados pessoais? Por exemplo, houve algum incidente de segurança devidamente registrado, inclusive com a elaboração de documento descrevendo o que ocorreu, quais medidas foram tomadas e como evitar que o incidente volte a acontecer?
2. Se aplicável, em que medida os dados pessoais serão tratados de forma distinta após a implementação do projeto / processo / sistema, comparado com a realidade atualmente?
3. Por que os dados pessoais estão sendo coletados? (ajuda)
4. Quantos titulares, aproximadamente, este projeto / processo / sistema irá afetar? Favor responder com porcentagem, por exemplo: "todos os clientes da empresa, 20% dos clientes, 2% dos indivíduos há mais de seis meses", etc. (ajuda)
5. Quem aprova alterações no projeto / processo / sistema no futuro?
6. Todas as partes interessadas, isto é, os titulares dos dados, estiveram envolvidas nas discussões sobre como seus dados pessoais serão utilizados? Para responder essa questão não é necessário indicar as partes interessadas no início do documento, apenas destacar aqui caso relevante, por exemplo, "os correntistas foram informados na ..." **[final cortado]**
7. Haverá tratamento de dados pessoais sensíveis? Se sim, quais? (ajuda)
8. Os dados tratados são os estritamente necessários para a finalidade de tratamento?
9. Qual a origem dos dados pessoais? Informar se os dados são coletados diretamente do titular ou se é coletado de alguma base de dado interna da Cia. (Liste/nomeie qualquer sistema interno associado a esse tratamento e explique por que existe essa associação.) (ajuda)
10. Como os dados pessoais são coletados/transferidos da fonte? Ex: Documento Físico, formulário WEB, documento digitalizado, entre outros. (ajuda)
11. Existe uma diferença entre a(s) finalidade(s) para a(s) qual(is) os dados foram coletados e a(s) finalidade(s) para a(s) qual(is) eles estão sendo usados?
12. Algum dado pessoal foi obtido por meio de terceiro(s)? Em caso afirmativo, nomeie-o(s) e indique qual a relação do terceiro com a Cia. (Indique qual o dado pessoal e para qual finalidade está sendo usado.)
13. Quem terá acesso aos dados pessoais envolvidos no processo? Por exemplo, quais departamentos/áreas da Cia terão acesso a quais dados pessoais especificamente? (ajuda)
14. Os dados pessoais serão acessados por seus titulares?
15. Caso os dados pessoais estejam sendo compartilhados externamente, quais contratos/acordos garantem a segurança dos dados pessoais?
16. Há transferência internacional dos dados pessoais? Se sim, fundamentada em qual dos mecanismos de transferência presentes na LGPD ou determinados pela ANPD? (ajuda)
17. Há auditorias em curso ou planejadas para registrar quem acessa os dados pessoais, quando etc.?
18. Quais medidas estão sendo adotadas para garantir a disponibilidade de acesso aos dados pessoais apenas àqueles com legitimidade para acessá-los?
19. Existe algum meio ou processo que permita a disponibilização dos dados pessoais aos seus titulares?
20. Onde e em que formato os dados pessoais serão mantidos durante todos os estágios em seu ciclo de vida? Por exemplo, os dados podem ser acessados e lidos livremente, ou há mecanismos de criptografia ou outro tipo de restrição para evitar que terceiros possam ter acesso aos dados? (ajuda)
21. Os dados pessoais serão mantidos atualizados? Como eles serão verificados quanto à precisão?
22. Por quanto tempo os dados serão mantidos? (ajuda)
23. Existe algum procedimento para recuperar dados pessoais em casos de Incidentes de Segurança?
24. Quais são os controles de segurança em vigor para os dados pessoais? (ajuda; no legado a resposta é uma lista de opções com "Outras (especifique)")
25. As decisões que envolvem dados pessoais são tomadas exclusivamente por meios automáticos? Por exemplo, não há uma avaliação feita por funcionários da Cia, mas apenas pelos sistemas para tomada de decisões sobre concessão de crédito ou outras atividades? Em caso afirmativo, forneça detalhes.
26. Qual é o risco potencial sobre os titulares caso haja divulgação não autorizada ou uso indevido dos dados pessoais?
27. O titular dos dados pessoais forneceu consentimento para o tratamento de seus dados para uma ou mais finalidades? Se sim, o consentimento é livre, informado e inequívoco? (ajuda)
28. O titular será capaz de retirar o consentimento?
29. Qual ou quais as Bases Legais para este tratamento de dados? Justifique: Se o tratamento dos dados pessoais é necessário para atender aos legítimos interesses da Cia ou de terceiros, favor preencher a seção 5 "Avaliação de Legítimo Interesse". Abaixo da pergunta o legado mostra, SÓ LEITURA e vindas da atividade: "Base Legal (Dados Pessoais)" e "Base Legal (Dados sensíveis)".

5. Quais mecanismos são utilizados para garantir a segurança do armazenamento dos dados pessoais? (ajuda; no legado a resposta é uma lista de opções com "Outros (especifique)")

## LIA (Avaliação de Legítimo Interesse), abas: Finalidade, Necessidade, Proporcionalidade, Logs

A lista da LIA tem busca por texto e filtro por Área, e colunas Atividade e Área. Botões da ficha: "Reabrir" e "Imprimir LIA".

### Finalidade (7 perguntas)
1. Para quais finalidades os dados pessoais serão tratados? (ajuda)
2. Quais benefícios serão auferidos pela Cia com o tratamento dos dados pessoais? Por exemplo, melhoria de processos internos, aperfeiçoamento de serviços, ganhos de competitividade ou financeiros, etc.
3. O tratamento dos dados pessoais beneficiará também a terceiros? Por exemplo, o próprio titular terá alguma vantagem com o tratamento de seus dados? Algum parceiro da Cia ou a própria sociedade terão algum benefício?
4. Qual a relevância dos benefícios identificados nos dois campos anteriores?
5. Quais as consequências da não realização do tratamento para a Cia?
6. O tratamento dos dados pessoais será realizado com base em regulamentações setoriais ou códigos e políticas específicas aplicáveis à Cia? Em caso positivo, favor especificar as regulamentações ou códigos e políticas.
7. Existe algum aspecto do tratamento dos dados pessoais que possa ser considerado antiético? Por exemplo, ainda que o tratamento não seja ilegal, trata-se de uma prática rejeitada pelo mercado ou de potencial questionamento ou repercussão social e midiática? Se sim, qual(is)?

### Necessidade (5 perguntas)
1. O tratamento dos dados pessoais é realmente necessário para atingir a finalidade?
2. O tratamento dos dados pessoais será realizado de forma proporcional à finalidade? Por exemplo, tudo o que se pretende fazer com os dados nesta atividade de tratamento está relacionado com a finalidade desejada?
3. A finalidade poderia ser alcançada sem o tratamento dos dados pessoais?
4. A finalidade poderia ser alcançada com o tratamento de quantidade menor de dados pessoais? Em caso positivo, favor informar quais são os dados estritamente necessários para alcançar a finalidade.
5. A finalidade poderia ser alcançada com o tratamento dos dados pessoais de forma menos danosa do que a que se propõe? Por exemplo, o tratamento poderia ser realizado com menos riscos para o titular?

### Proporcionalidade (11 perguntas)
1. Os dados pessoais a serem tratados são considerados dados sensíveis (dado pessoal sobre origem racial ou étnica, convicção religiosa, opinião política, filiação a sindicato ou a organização de caráter religioso, filosófico ou político, dado referente à saúde ou à vida sexual, dado genético ou biométrico, quando vinculado a uma pessoa natural)?
2. Existe uma relação formal com o titular cujo dado se pretende tratar? Se sim, de qual natureza? (ajuda)
3. Já foram tratados dados pessoais deste mesmo titular anteriormente? Se sim, para qual finalidade?
4. Os dados pessoais foram coletados diretamente do titular, ou seja, fornecidos diretamente por ele para a Cia? Se sim, para qual finalidade? (ajuda)
5. Se os dados pessoais foram coletados por terceiros, incluindo correspondentes bancários, o titular está ciente do compartilhamento de seus dados pessoais? Se sim, qual a prova dessa ciência? Por exemplo, há algum documento, aceite, registro ou outra forma de demonstrá-la?
6. Há quanto tempo os dados pessoais foram coletados?
7. Desde a coleta dos dados pessoais, houve alguma alteração tecnológica ou contextual que poderia afetar as expectativas originais do titular? Por exemplo, os dados pessoais passaram a ser utilizados de alguma forma distinta da originalmente prevista ou para finalidades diferentes daquelas originalmente informadas ao titular?
8. As técnicas que serão utilizadas para o tratamento dos dados pessoais são adequadas e seguem razoavelmente as técnicas de proteção de dados? Por exemplo, o tratamento adotará mecanismos de segurança e outros padrões exigidos e praticados pelo setor?
9. Os dados pessoais serão tratados para a realização de algo novo ou inovador? Por exemplo, algum produto ou serviço diferente e fora das práticas normais de mercado?
10. Existe algum registro apto a comprovar a expectativa original do titular em relação ao tratamento de seus dados pessoais? Por exemplo, no contrato, ou em outra documentação vinculada ao titular, cláusula ou texto explicando como e por que os dados pessoais serão tratados?
11. Existe algum registro que permita definir se os titulares estão ou não cientes de que tratamento como o que se pretende poderia vir a ser realizado? Por exemplo, no contrato ou outra documentação vinculada ao titular, cláusula ou texto esclarecendo que haverá tratamento de dados pessoais e a respectiva finalidade desse tratamento?
